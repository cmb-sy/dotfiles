# tab-title

## 名前を決める

引数があれば、それをそのまま名前にする。

無ければ次の形で作る。

```
#<番号> <題>
```

番号は次の順で探し、最初に見つかったものを使う。どちらも無ければ番号を付けず題だけにする。

1. ブランチ名が `<type>/<数字>-` の形なら、その数字（`git branch --show-current`）
2. 会話で今取り組んでいる作業の issue 番号

題は今の作業を表す日本語の名詞句で、10 文字以内にする。「対応」「作業」とリポジトリ名は入れない。

## 改名する

```bash
"$HOME/dotfiles/bin/herdr-tab-title" "<名前>"
```

herdr の外では何も起きない。結果は報告しない（1 行も書かない）。そのまま作業を続ける。
