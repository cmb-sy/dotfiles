# vim コマンド

ツリーで `Space`、ファイル側で `Space m`。閉じるのは `Space` だけ。

## まずこれだけ

| キー | 動作 |
|---|---|
| `i` | 入力を始める |
| `Esc` | 入力をやめる（迷ったら押す） |
| `:w` | 保存 |
| `:q` | 閉じる |
| `:wq` | 保存して閉じる |
| `:q!` | 保存せず捨てる |
| `:qa` | 全部閉じる（ツリーも一緒に） |
| `u` | 元に戻す |
| `Ctrl+r` | やり直す |

## 移動

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` / `b` | 次の単語 / 前の単語 |
| `0` / `$` | 行頭 / 行末 |
| `gg` / `G` | ファイル先頭 / 末尾 |
| `:42` | 42 行目へ |
| `Ctrl+d` / `Ctrl+u` | 半画面 下 / 上 |
| `%` | 対応する括弧へ飛ぶ |
| `{` / `}` | 段落単位で 前 / 次 |

## 編集

| キー | 動作 |
|---|---|
| `x` | 1 文字消す |
| `dd` | 1 行消す |
| `dw` | 単語を消す |
| `D` | カーソルから行末まで消す |
| `yy` | 1 行コピー |
| `p` / `P` | 下に貼る / 上に貼る |
| `cw` | 単語を書き換える |
| `cc` | 行を書き換える |
| `o` / `O` | 下に / 上に 行を作って入力 |
| `A` | 行末から入力 |
| `.` | **直前の操作をもう一度** |

`.` が vim の核心です。`cw` で単語を直したあと次の単語で `.` を押すと同じ書き換えが繰り返されます。

## 数を前に付ける

`3dd` で 3 行削除、`5j` で 5 行下、`2yy` で 2 行コピー。ほぼ全てのキーに付けられます。

## 範囲を選ぶ

| キー | 動作 |
|---|---|
| `v` | 文字単位で選択 |
| `V` | 行単位で選択 |
| `Ctrl+v` | 矩形で選択（縦に揃えて消す・入れる） |

選んだあと `d` 削除 / `y` コピー / `>` 字下げ / `<` 戻す。

## 検索と置換

| キー | 動作 |
|---|---|
| `/語` | 下方向に検索（`?語` で上方向） |
| `n` / `N` | 次の一致 / 前の一致 |
| `*` | カーソル下の単語を検索 |
| `:%s/前/後/g` | ファイル全体を置換 |
| `:%s/前/後/gc` | 1 件ずつ確認しながら置換 |

`Esc` で検索の色を消せます（この設定では同時にツリーへ戻ります）。

## ウィンドウ

| キー | 動作 |
|---|---|
| `Ctrl+w` → `h` / `l` | 左 / 右のウィンドウへ |
| `Ctrl+w` → `q` | このウィンドウを閉じる |
| `Ctrl+w` → `=` | 幅を揃える |

# この設定だけのキー

## どこでも

| キー | 動作 |
|---|---|
| `Space` `?` | **全キーの一覧**（迷ったらこれ） |
| `Space` `e` | ツリーの開閉 |
| `Space` `f` | ファイル名で探す |
| `Space` `g` | 本文を横断検索 |
| `Space` `b` | 開いているファイル一覧 |
| `Space` `m` | このメモ |
| `Esc` | ツリーへ戻る |

## ツリーの中

| キー | 動作 |
|---|---|
| `Space` | このメモ |
| `Enter` | 開く（フォルダなら開閉） |
| `P` | プレビュー（開かずに右へ中身を出す） |
| `]g` / `[g` | git で変更のあるファイルへ |
| `s` / `S` | 左右に分けて開く / 上下に分けて開く |
| `z` | 全フォルダを閉じる |
| `?` | ツリーのキー一覧 |

## 変更箇所を追う

| キー | 動作 |
|---|---|
| `]c` / `[c` | 次 / 前の変更行へ |
| `Space` `h` `p` | その変更の差分を表示 |
| `Space` `h` `d` | ファイル全体を HEAD と比較 |

## 外のツール

| キー | 動作 |
|---|---|
| `Cmd+Ctrl+G` | lazygit（使い捨てペイン、`q` で閉じる） |
| `Cmd+Opt+T` | herdr のタブを増やす |
| `Cmd+Shift+F` | ディレクトリをあいまい検索して移動 |
| `Ctrl+T` | ファイルをあいまい検索 |
